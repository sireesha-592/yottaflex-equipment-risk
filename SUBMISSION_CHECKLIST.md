# Submission Checklist

- [ ] Run starter generation from a clean environment.
- [ ] Run `pytest`.
- [ ] Inspect output tables, especially `ground_truth.csv`.
- [ ] Run validation and understand every reported issue.
- [ ] Run reproducibility twice and investigate any mismatch.
- [ ] Review whether full target scale runs within available memory/time.
- [ ] Read and verify all generated documentation.
- [ ] Update `PROMPT_HISTORY.md` with all prompts used.
- [ ] Confirm no secrets or private data are present.
- [ ] Create a new public GitHub repository and push project files.
- [ ] Test repository link in a private/incognito browser window.
- [ ] Submit repository link on the candidate portal before the deadline.
